# HealthMate 前端联调所需后端接口与字段

> 说明：前端不能直接修改后端代码。本文件只列出前端联调所需的后端接口、字段和兼容要求，供后端同学确认或实现。

## 1. 必须新增或确认的接口

| 优先级 | 需求 | 当前影响 | 建议后端提供 |
| --- | --- | --- | --- |
| P0 | 获取当前登录用户档案 | 前端刷新页面后只有 token，无法恢复 `gender/height/weight/healthGoal/medicalHistory/profileCompleted` | `GET /api/profile` |
| P0 | 档案完成状态 | 前端路由需要判断是否进入 `/profile-setup` 还是 `/dashboard` | 在 `GET /api/profile` 和 `POST /api/profile` 返回 `profileCompleted` |
| P1 | 登录返回基础用户信息 | 可减少登录后额外请求档案接口 | 可选：`POST /api/auth/login` 返回 `userId/username/profileCompleted` |

## 2. `GET /api/profile` 需求

| 项目 | 要求 |
| --- | --- |
| 方法 | `GET` |
| 路径 | `/api/profile` |
| 鉴权 | `Authorization: Bearer <token>` |
| 成功 HTTP 状态 | `200` |
| 统一响应 | `{ "code": 0, "message": "查询成功", "data": {...} }` |

建议返回：

```json
{
  "code": 0,
  "message": "查询成功",
  "data": {
    "userId": 1,
    "username": "test001",
    "gender": 1,
    "height": 175,
    "weight": 68,
    "healthGoal": "减脂",
    "medicalHistory": "无",
    "healthGoalVersion": "2026-05-10T12:00:00",
    "profileCompleted": true
  }
}
```

字段说明：

| 字段 | 类型 | 必需 | 前端用途 |
| --- | --- | --- | --- |
| `userId` | number | 是 | 展示、状态标识 |
| `username` | string | 建议 | 用户昵称展示 |
| `gender` | number/null | 是 | 档案回填，`0` 未知、`1` 男、`2` 女 |
| `height` | number/null | 是 | 档案回填 |
| `weight` | number/null | 是 | 档案回填 |
| `healthGoal` | string | 是 | 首页、任务页、档案页展示 |
| `medicalHistory` | string/null | 是 | 档案页展示 |
| `healthGoalVersion` | string/null | 建议 | 目标更新时间展示或后续缓存判断 |
| `profileCompleted` | boolean | 是 | 前端路由判断是否需要完善档案 |

## 3. `POST /api/profile` 返回字段建议

当前后端已有 `POST /api/profile`，请求字段可满足前端。建议返回值与 `GET /api/profile` 保持一致。

| 字段 | 当前是否已有 | 建议 |
| --- | --- | --- |
| `userId` | 已有 | 保持 |
| `gender` | 已有 | 保持 |
| `height` | 已有 | 保持 |
| `weight` | 已有 | 保持 |
| `healthGoal` | 已有 | 保持 |
| `medicalHistory` | 已有 | 保持 |
| `username` | 缺少 | 建议补充 |
| `healthGoalVersion` | 缺少 | 建议补充 |
| `profileCompleted` | 缺少 | 建议补充 |

建议返回：

```json
{
  "code": 0,
  "message": "保存成功",
  "data": {
    "userId": 1,
    "username": "test001",
    "gender": 1,
    "height": 175,
    "weight": 68,
    "healthGoal": "减脂",
    "medicalHistory": "无",
    "healthGoalVersion": "2026-05-10T12:00:00",
    "profileCompleted": true
  }
}
```

## 5. 如果后端暂时不提供 `GET /api/profile`

前端会出现这些限制：

| 场景 | 影响 |
| --- | --- |
| 用户刷新页面 | 只有 token，无法从后端恢复档案状态 |
| 老用户登录 | 登录接口只返回 token/userId，前端无法知道是否已经完善档案 |
| 路由守卫 | 无法可靠判断跳转 `/profile-setup` 还是 `/dashboard` |
| 个人页 | 无法展示真实身高、体重、目标、病史 |

临时方案只能使用 localStorage 缓存档案，但这不属于“完全使用后端提供内容”，不建议作为正式联调方案。
