## 2. 本次已完成的前端改动

| 模块 | 改动 | 文件 |
| --- | --- | --- |
| HTTP 鉴权 | 401 时清理 token，并触发全局 `healthmate:auth-expired` 事件 | `src/services/http.js` |
| 路由守卫 | 监听 auth 失效事件，统一执行 logout | `src/router/guards.jsx` |
| Store | `addTasks` 改为按 `task.id` 合并，避免 SSE 重复任务 | `src/store/AppStore.jsx` |
| SSE Hook | 每次 `connect()` 前先关闭旧连接，避免多个 EventSource 并发 | `src/hooks/useSSEAdvice.js` |
| AI 建议页 | 收到 SSE tasks 后先写入前端，再请求 `/task/today` 校准后端状态 | `src/pages/AIAdvice/AIAdvicePage.jsx` |
| AI 建议页 | 任务打卡成功后重新请求 `/task/today`，保证状态来自后端 | `src/pages/AIAdvice/AIAdvicePage.jsx` |
| Dashboard | 今日任务打卡成功后重新请求 `/task/today`，同步完成率 | `src/pages/Dashboard/DashboardPage.jsx` |
| 任务页 | 任务打卡成功后重新请求 `/task/today` 和 `/task/history`，同步列表和完成率 | `src/pages/Tasks/TasksPage.jsx` |
